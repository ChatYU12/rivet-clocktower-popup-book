# 小铆钉的钟楼之旅

一本可以在浏览器里翻的 3D 立体书。机械复古风格，原创故事，五个章节。

- 拖动书页翻页（也可以用方向键或底部按钮）
- 书页翻开时，金属零件会立起来；翻过去时会折平
- 每章点一下发光的齿轮就能盖章，那座钟楼的指针也会开始转

## 运行

直接用浏览器打开 `index.html` 就行，不需要构建。依赖 three.js r128（从 cdnjs 加载）和 Google Fonts。

## 结构

- `index.html`：整本书都在这一个文件里。三维场景用 three.js；所有立体零件、主角和封面都是代码生成的 SVG，运行时栅格化成贴图
- `故事脚本与资产清单.md`：故事脚本和美术资产清单

灵感来自 John Lindquist 的 The Folded Atlas。
