# 小铆钉的钟楼之旅

一本可以在浏览器里翻的纸艺 3D 立体书，原创故事，共五个章节。

- 拖动书页翻页，也可以用方向键或底部按钮
- 拖动书外的空白处可以绕中心旋转，滚轮缩放，点「回正」恢复正面视角
- 书页翻开时纸板零件会立起来，翻过去时又折平；书本有硬壳封面、书脊和书页块的厚度
- 每章点一下发光的齿轮就能盖章，对应钟楼的指针也会开始转
- 没有显卡加速的浏览器（比如 Claude 桌面版的内置浏览器）会自动改用 CSS 3D 渲染

## 运行

需要通过网页服务器打开（比如 GitHub Pages，或者在本地运行 `python3 -m http.server`），不需要构建。直接双击 `index.html` 时，浏览器会拦截本地图片，贴图加载不出来。

依赖：three.js r128（从 cdnjs 加载）和 Google Fonts。

## 结构

- `index.html`：整本书的代码，包括三维场景、翻页、视角旋转、补充的 SVG 纸艺配件（灌木、小屋、飞艇、风车、路牌等）
- `assets/`：纸艺资产图（WebP，由原始 PNG 压缩而来）
- `故事脚本与资产清单.md`：故事脚本和资产清单

灵感来自 John Lindquist 的 The Folded Atlas。
